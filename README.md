Repositório dedicado aos meus estudos e à prática de **Java**, criado para reunir exercícios, exemplos e pequenos projetos desenvolvidos durante meu processo de aprendizado.

O objetivo é fortalecer minha base na linguagem, revisar conceitos importantes e evoluir gradualmente até o desenvolvimento de aplicações back-end com **Java e Spring Boot**.

## Conteúdos praticados

Neste repositório, estou estudando e praticando os seguintes conteúdos:

- Sintaxe básica do Java;
- Variáveis, tipos de dados e operadores;
- Entrada e saída de dados;
- Estruturas condicionais;
- Estruturas de repetição;
- Métodos e sobrecarga;
- Vetores, matrizes e listas;
- Classes, atributos e objetos;
- Construtores e encapsulamento;
- Enumerações e composição;
- Herança e polimorfismo;
- Classes abstratas e interfaces;
- Tratamento de exceções;
- Leitura e escrita de arquivos;
- Generics;
- Collections: `List`, `Set` e `Map`;
- Expressões lambda;
- Interfaces funcionais;
- Stream API;
- JDBC e integração com banco de dados;
- Fundamentos de Spring Boot e APIs REST.

## Tecnologias e ferramentas

- **Java 24** — versão configurada atualmente no projeto;
- **IntelliJ IDEA** — ambiente de desenvolvimento;
- **Git e GitHub** — versionamento e armazenamento dos códigos;
- **PostgreSQL** — banco de dados utilizado nos estudos de persistência;
- **Spring Boot** — framework utilizado na evolução para o back-end.

## Organização do repositório

Os arquivos serão organizados por assunto conforme os estudos avançarem. Cada diretório poderá conter:

- Exemplos desenvolvidos durante as aulas;
- Exercícios de fixação;
- Desafios de lógica e Programação Orientada a Objetos;
- Anotações aplicadas em código;
- Pequenos projetos para integrar os conceitos estudados.

## Como executar

### IntelliJ IDEA

1. Clone o repositório;
2. Abra a pasta do projeto no IntelliJ IDEA;
3. Configure um JDK compatível;
4. Abra a classe que deseja executar;
5. Execute o método `main` pela opção **Run**.

### Terminal

```bash
git clone https://github.com/chxvxxs/Java-Study.git
cd Java-Study
javac -d out src/Main.java
java -cp out Main
```
